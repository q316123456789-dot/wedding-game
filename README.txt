婚禮手機網頁密室逃脫｜粉色 UI 完整專案

【開啟方式】
1. 解壓縮 ZIP。
2. 直接雙擊 index.html，即可用 Chrome 開啟。
3. 不需要伺服器、不需要安裝套件。

【圖片替換】
所有圖片都在 assets/。
請直接用自己的照片覆蓋同名 JPG：
001.jpg, 002.jpg, 003.jpg,
w1.jpg, w2.jpg, w3.jpg,
wd1.jpg, wd2.jpg, wd3.jpg, wd4.jpg,
w4.jpg, w51.jpg, w52.jpg, w6.jpg, w7.jpg,
e1.jpg, e650.jpg, ec650.jpg,
E2.jpg, E9487.jpg, E5.jpg, E94520.jpg, Egg.jpg

圖片 CSS 採「寬度 100%＋高度 auto＋object-fit: contain」，
不固定裁切高度。替換成不同尺寸的原圖後，圖片區會依原圖比例自然匹配，
不會硬裁成固定比例。

【UI】
依參考圖片採浪漫粉色、霧粉背景、白色圓角卡片、玫瑰粉漸層按鈕、
香檳金裝飾、花瓣與柔光效果；手機優先並可響應式放大。

【流程】
HTML 保留 23 個遊戲頁面容器；JavaScript 依 Word 腳本逐步串接完整劇情與題目，
需要中間轉場時會在同一套頁面容器中更新內容，不會顯示多餘的章節標題或進度條。

【重要】
- 不顯示進度條。
- 不顯示「遊戲一：新娘篇」「遊戲二：新郎篇」等章節 Heading。
- 畫面不顯示答案本身。
- 控場題「我獨自升級」「開始玩耍」「彩蛋」不提供提示。
- 答錯會紅框晃動並顯示「答案好像不太對唷，再努力想想看」。
- 答對會顯示「✓ 答案正確！」與灑花動畫，再自動進入下一頁。
