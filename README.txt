# 婚禮手機網頁密室逃脫

依《遊戲題 (3).docx》建立的 Mobile-First 靜態 Web 遊戲。

## 使用方式
1. 將整個資料夾上傳到任何可提供靜態網站的空間。
2. 開啟 index.html 即可遊玩。
3. 將自己的照片直接覆蓋 assets/ 內同名 JPG 即可替換占位圖。
4. 不需要修改 HTML；題目判定集中在 script.js。

## 設計
- 霧粉背景 #FFF5F6
- 白色圓角卡片 #FFFFFF
- 玫瑰粉漸層按鈕 #E88D9C
- 香檳金 #D4AF37
- Mobile-First / RWD
- 答對：綠色「✓ 答案正確！」動畫
- 答錯：顯示「答案好像不太對唷，再努力想想看」並晃動輸入框
- 不顯示進度條、章節標題與答案本身

## 圖片
assets/ 內已建立 23 個指定檔名的空白預設 JPG 占位圖。

## 關於「23 頁」
Word 檔為 23 個文件頁面，但其中若干頁同時包含「輸入後跳到新的畫面」的多個流程狀態，以及圖片頁指示。
因此專案保留 23 個文件頁 HTML template，並在 script.js 將所有「跳到新的畫面」拆成可互動狀態，避免刪掉劇本內容。
